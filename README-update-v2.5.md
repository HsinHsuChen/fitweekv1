# FitWeek v2.5.0 更新說明

課表 v2.2。更新日期：2026-10-20。

## 更新到原本的 GitHub Pages

1. 在舊版設定先匯出完整 JSON 備份，檔案留在手機或電腦。
2. 解壓縮更新包，把包內所有檔案上傳到原本儲存庫的根目錄，覆蓋同名檔案，再提交。
3. 等 GitHub Pages 發布完成，重新開啟原網址並重新整理，到「設定」確認 v2.5.0。

沿用原網址、瀏覽器和主畫面入口，可繼續使用本機紀錄。發布更新不需要清除瀏覽器資料。這個更新包沒有替你發布到 GitHub。

## 四個入口

- 訓練：ABC／D選擇、開始時間、身體狀況、上次同條件紀錄、逐組輸入、動作圖示與休息倒數。
- 飲食：按日期獨立記錄，休息日也能填；每餐可放6張壓縮照片。文字請註明自己實際吃的份量。當日多筆訓練共用當日飲食，單獨記飲食不增加運動次數。
- 回顧：本週摘要、每週重量建議、依課表篩選的歷史、歷史修改、完整課表。
- 設定：完整備份與還原、桌面小工具、主畫面安裝與更新說明。

## 訓練紀錄

- 可以先按「開始訓練」。忘了按時，第一次填入大於0的次數會自動開始計時；單純瀏覽、填飲食或挑重量不會開始。
- 只填標準完成的次數；0下與留白不算完成組。RPE選單附剩餘次數，例如8代表約可再做2下。
- 畫面最上方顯示儲存狀態；完成後會另存正式紀錄。返回修改，再完成儲存，更新同一筆紀錄與原時間。
- 當日另一次訓練，請按「開始新一筆訓練」。每筆有效訓練依原來03:00規則加1次。
- 歷史「修改」可修正重量、次數、RPE、動作品質、備註、身體狀況與實際時間；Cindy可修正輪數、零星次數與動作版本。修改後重新檢視每週建議與連續紀錄。
- 日期依台灣時間。跨午夜的同一筆訓練以實際起始日記錄；已顯示的動作順序在這筆訓練內固定。
- 啞鈴重量按單支填寫；總量區分兩支同時使用、單支使用及單側兩側計算。總量適合比較同動作，不能單獨代表訓練品質。
- 未填疼痛或飲食欄位保留未記錄，不會當成0分或未達標。

## 飲食與舊資料

新飲食資料按日期保存，修改當日飲食後，歷史報告會使用該日更新的內容。舊紀錄、退休動作、清單外重量與隱藏組數仍保留；讀取舊紀錄時會重算啞鈴總量。舊版同一課表、相同起始時間的重複儲存，在歷史列表合併顯示；完整備份仍保留原始資料。

分享主按鈕會帶入報告和照片；裝置不支援多檔分享時改下載報告包。「完整備份」另包含所有歷史、草稿、飲食與設定，與單次ChatGPT報告包用途不同。

## 小工具與節拍器

v2.4.0的每日03:00檢查、同區間每筆加1次、週日休息區間，以及五種顏色激勵語沿用。小工具程式未變更，完成訓練後仍需手動同步。更早版本的安裝方式見README-widget.md。

節拍器保留60BPM、首拍重音與背景恢復機制。網頁會顯示播放／恢復狀態；iOS背景音訊與桌面更新仍由系統管理，沒有宣稱縮小或鎖定螢幕一定不中斷。
