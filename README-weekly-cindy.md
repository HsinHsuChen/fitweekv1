# v2.3.2：每週重量建議、Cindy D日與週日休息

App v2.3.2，課表 v2.2。A／B／C的動作、組數與次數沿用原設定，新增手動選擇的D日。

## 更新與使用

將更新包所有檔案上傳到原GitHub儲存庫根目錄。發布後重新整理，確認App v2.3.2。

這次連續計數規則有調整：請在網頁「設定」重新複製小工具程式，替換Scriptable裡 **FitWeek-Streak** 的全部內容，再按「同步到桌面」。v2.2.1的火焰與5種配色仍保留。

## 每週重量檢視

「課表」頁展開「每週重量檢視與建議」。依台灣時間，每週一至週日為一週，當週檢視上一個完整星期。週期內不必每天變動重量。

每個動作顯示最近實際重量、次數、RPE及維持／降重／加重理由；A日肩優先與胸優先分開比較。可以勾選後套用到之後新紀錄的建議值，目前輸入及歷史紀錄不會被改寫。已採用的建議會沿用，直到你套用新的建議。

- 每組都達次數上限、同重量連續兩次、每組RPE≤8且動作品質選「全程標準」，才考慮加重。至少一筆須在上週，其餘可參考之前28天。
- 加重上限採保守的10%；如果器材最小一檔跳得太多，維持原重量並回報，先評估單組試重，不直接整套加重。
- 最近有RPE10、動作變形，或同重量連續兩次RPE≥9，建議降一檔，由你決定是否採用。
- 有關節疼痛則先評估，不自動調整；上週有睡眠不足6小時則暫不加重。
- 沒填RPE或動作品質、紀錄不足、混合重量可能包含暖身，都不會判為可加重。
- 星期更新時會重新檢視。反覆套用同一份建議不會再加一檔。
- 本週最新紀錄若有疼痛、RPE10或動作變形，會立即暫停建議重量，先回報與調整，不需要等到下一週。已記錄的實際重量仍保留。
- 本功能只提供保守建議，未完成的草稿不納入，Cindy不納入啞鈴加重。

## D日 Cindy

在今日訓練按D，使用20分鐘計時：每輪5引體向上、10伏地挺身、15徒手深蹲，盡量維持標準動作。

你目前徒手引體穩定3下，因此預設為彈力帶輔助引體與上斜伏地。可選動作版本、記錄彈力帶掛法、模式與整體RPE。先配速、保留餘力；不要為追輪數做變形動作。

填完整輪數，再填最後一輪按順序完成的零星次數。例如6輪後再完成5引體與2伏地：填6輪、引體5、伏地2、深蹲0，成績為 **6輪＋7下，共187次**。系統也會算出引體35、伏地62、深蹲90。

按「完成訓練」後，可照常匯出報告、分享餐點照片、備份JSON與同步桌面。未滿20分鐘可提前停止，按實際時間紀錄；休息時間算在20分鐘內。只有20分鐘、相同模式、動作版本及彈力帶掛法才比較PR。輔助引體未填彈力帶設定不判PR。

Cindy是全身體能訓練，不能當作沒有負荷的休息日。建議取代一次重訓，或恢復良好時選做，不自動把它排成每週必做。星期日可以完全休息。

## 週日保留連續紀錄

24小時計時遇到台灣時間星期日，會暫停；休息日保留目前次數，不額外增加。每筆有效訓練增加1次，同一天也可接續；相同訓練重複儲存只算1次。實際完成D日也算1次。

例：週六22:00起始 → 週日完全休息 → 期限延至週一22:00。週一在期限內起始就接續；超過才歸零。若週六以前已經因超時中斷，星期日不會恢復舊次數。

網站與更新後的Scriptable使用同一套規則。iOS決定桌面刷新時間，可能延後；小工具仍會顯示接續期限與上次同步時間。

官方背景資料：[CrossFit Cindy](https://www.crossfit.com/benchmark/cindy)、[ACSM阻力訓練指引](https://acsm.org/resistance-training-guidelines-update-2026/)。上述週期判斷與10%限制是本網頁採用的保守規則，並非保證增肌的門檻。

動作載入已加上保護。若發布未完成，頁面會顯示原因；不必清除瀏覽器資料或刪除訓練紀錄。
