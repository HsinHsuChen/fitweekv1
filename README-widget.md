## 一次設定

1. 在 iPhone 安裝 [Scriptable](https://apps.apple.com/tw/app/scriptable/id1405459188)。
2. 在訓練網頁「設定」按「複製小工具程式」。
3. 開啟 Scriptable，按＋新增程式，貼上全部內容。將程式名稱設成 **FitWeek-Streak**，大小寫與連字號都相同。
4. 回到原本的訓練網頁，按「同步到桌面」。Scriptable 會儲存資料並顯示小工具預覽。
5. 長按 iPhone 主畫面空白處 → 編輯 → 加入小工具 → Scriptable → 選小尺寸。
6. 長按這個小工具 → 編輯小工具 → Script → 選 **FitWeek-Streak**。

如果複製功能不可用，設定頁會顯示完整程式碼，長按選取全部再複製。也可下載 `FitWeek-Streak.js` 查看內容。

## 每次使用

從你原本使用的 Safari 或主畫面網頁入口記錄訓練。完成後按「完成訓練」，再按上方「同步到桌面」。Scriptable 會顯示新的次數、期限及同步時間；確認預覽後回到原本的網頁入口即可。

桌面小工具無法直接讀取 Safari／主畫面網頁的本機紀錄，因此這版需要按一次同步。網頁計數本身會自動更新。只傳送計數、時間及網站網址，不傳送動作內容、健康欄位或餐點照片；不需要額外伺服器。

## 計數規則

- 必須按「完成訓練」儲存，且至少有1組的次數大於0。未完成的草稿與空白紀錄不計入。
- 第一次有效紀錄顯示1次。
- 下一筆有效紀錄的**起始時間**距離上一筆起始時間不超過24小時（週日暫停計時），就接續本輪。
- 每筆不同的有效訓練增加1次，同一天也可接續並更新期限，不必等到跨日。
- 超過最新有效紀錄起始時間24小時後顯示0（不計週日的時間）；下一筆從1重新開始。
- 剛好相隔24小時仍可接續；超過才中斷。
- 台灣日期依訓練起始時間判定，跨午夜的同一筆訓練仍只算1次。
- 反覆對同一筆訓練按完成，或重複匯入備份，不會增加次數，也不會把原起始時間改成儲存時間。
- 同一天要開始另一次訓練，可在完成畫面按「開始新一筆訓練」；會保留當日飲食與重量，清空新一筆的次數、RPE與動作備註。
- 既有紀錄會自動納入；缺少起始時間時使用完成時間，完全沒有時間資料則不計入。匯入備份後會重算。
- 週日為休息日，暫停24小時計時；休息保留次數、不增加1次。若實際完成D日則照有效紀錄計算。

例：凌晨01:00開始，當天20:00再開始另一筆有效訓練 → 2次，期限延至隔天20:00。不需要等到午夜後才增加。

網站會從既有完整紀錄重算，不改寫歷史資料。舊版小工具只存有「天數」摘要，無法單靠摘要還原每筆次數；在重新同步前，新版小工具會顯示「—」與重新同步提示，不會把舊天數當成新次數。

## 桌面刷新限制

iOS 決定小工具何時刷新，不能保證剛好到24小時就立即重畫數字。程式會要求在期限附近刷新，並在每次刷新時重新判斷是否歸零。畫面同時印出接續期限與上次同步時間；網頁在開啟及回到前景時會依當下時間判斷。

如果預覽正確、桌面暫時仍是舊數字，先等 iOS 刷新，或長按小工具檢查是否選到 **FitWeek-Streak**。
