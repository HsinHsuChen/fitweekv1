# FitWeek iPhone 桌面小工具｜v2.4.0

網站與桌面小工具共用「每日03:00檢查、每筆訓練加1次」規則。

## 更新

1. 將更新包全部14個檔案上傳覆蓋原GitHub儲存庫根目錄，發布後重新整理，確認顯示App v2.4.0。
2. 在網頁「設定」按「複製小工具程式」，覆蓋Scriptable中 **FitWeek-Streak** 的全部內容，儲存。
3. 回到網頁按「同步到桌面」，確認預覽的次數、期限及同步時間。

既有完整訓練紀錄會依新規則重算，歷史資料不會被改寫。舊版小工具只有舊規則摘要，無法自行重建新計數；更新程式但尚未重新同步時，顯示「—」與同步提示。

## 計數規則

- 使用台灣時間UTC+8，以每天03:00為分界，一個區間為當天03:00至隔天03:00前。
- 每天03:00檢查剛結束的24小時區間：有有效訓練就接續，沒有則中斷。尚未結束的區間不會提早判定缺席。
- 每筆不同的有效訓練加1次；同一區間可以累計多次，第二次也算。多練一次不會抵銷未來空白的區間。
- 有效訓練必須按「完成訓練」儲存，且至少有一組的次數大於0；草稿與空白紀錄不計。
- 依訓練起始時間歸入區間；03:00整屬於下一個區間。跨午夜或跨03:00的同一筆訓練，只算1次。
- 同一訓練重複按完成或重複匯入備份，不會重複加算。以相同起始時間與課表辨識同一訓練。
- 同一天開始另一次訓練時，請按完成畫面的「開始新一筆訓練」，保留飲食及重量，重新填這次的次數與RPE。
- 週日03:00至週一03:00為選配休息區間，不運動保留次數、不加1；實際完成D日或其他有效訓練仍加1次。
- 週一03:00至週二03:00仍須有有效訓練，否則週二03:00中斷。週日不能恢復先前已中斷的計數。
- 中斷後顯示0；下一筆有效訓練從1重新開始。
- 舊紀錄缺少起始時間時使用完成時間；兩者都沒有時不計入。原報告日期、課表排程與每週重量檢視仍使用原本的實際日期。

## 例子

| 紀錄 | 結果 |
|---|---|
| 週二08:00、週二20:00各完成一筆 | 累計2次；兩筆都屬週二03:00起的區間 |
| 週二04:00、週三23:00各完成一筆 | 即使相隔43小時，兩個相鄰區間都有紀錄，仍接續算2次 |
| 週二有練，週三03:00至週四03:00沒有紀錄 | 週四03:00中斷；週四03:00整的新訓練從1開始 |
| 週六22:00完成、週日休息、週一22:00再完成 | 保留並接續算2次；若週一整個區間都沒練，週二03:00才中斷 |

## 配色與激勵語

每次小工具刷新會從原本5種配色中選一種，每種配色都有專屬的訓練、休息與重新開始文案。

| 配色 | 訓練中的激勵語 |
|---|---|
| 橘色 | 每次累積，都算進步 |
| 紫色 | 一步一步，靠近目標 |
| 藍色 | 照著自己的節奏前進 |
| 綠色 | 穩穩練習，慢慢變強 |
| 粉色 | 願意開始，就很棒了 |

同步失敗、需要更新或尚未設定時，優先顯示操作提示。

## 第一次設定與日常同步

iPhone安裝Scriptable，新增程式並將名稱設為 **FitWeek-Streak**，貼上網頁設定提供的完整內容。長按主畫面新增小尺寸Scriptable小工具，再編輯小工具並選擇此程式。

網頁本機資料不能直接由Scriptable讀取，完成訓練後仍需按「同步到桌面」。只傳送計數、時間與網站網址，不傳送健康或餐點照片。請持續使用原來的Safari或主畫面網頁入口。

iOS決定桌面實際刷新時間，不能保證03:00準時重畫；程式會要求在03:00附近刷新，並在每次執行時按當下時間重算是否中斷。期限及上次同步時間會顯示在小工具上。網站開啟、回前景或保持開啟至分界時，也會重算。

官方說明：[Scriptable URL Scheme](https://docs.scriptable.app/urlscheme/)、[ListWidget](https://docs.scriptable.app/listwidget/)、[Apple WidgetKit刷新機制](https://developer.apple.com/documentation/widgetkit/keeping-a-widget-up-to-date)。
